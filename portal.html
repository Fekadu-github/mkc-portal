Security status

Authentication: Supabase Auth · Database: PostgreSQL · Access control: Row-Level Security · MFA: authenticator-app support · Audit: database triggers · Backups: configure Supabase backups and an off-site encrypted backup policy.

Data governance

Use reports for ministry planning. Do not share personal information outside authorized church leadership. Member data is accessed only through authenticated sessions and database RLS policies.
